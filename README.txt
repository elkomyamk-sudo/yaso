ارفع محتويات هذا المجلد كلها إلى جذر مستودع GitHub (وليس المجلد نفسه داخل مجلد آخر):
- index.html
- مجلد assets وفيه song.mp3 و friendship.svg
- .nojekyll

مشغل الأغنية ظاهر داخل الموقع، ويمكن تشغيلها بالضغط على زر التشغيل أو مشغل الصوت.
بعد رفع الملفات إلى فرع main في جذر المستودع، تأكد من إعدادات Settings > Pages أن النشر من main و /(root).
